# 架构决策记录

## ADR-001：默认直接生成MP4

现状：当前主路由使用FFmpeg完成独立渲染。理由：时间线和资源可在本地校验，成品可独立检查；外部编辑器原生草稿作为兼容路线。代价：只能承诺实际实现的效果，不承诺外部编辑器专属效果完全一致。

## ADR-002：模型计划与确定性编译分离

现状：模型生成结构化候选，代码核验来源、区间、时长和支持元素。理由：减少自由文本直接控制执行的风险，保留错误依据。代价：候选不足或语义不可分时可能需要有界修订或用户处理。

## ADR-003：原声混剪的前四十秒由程序锁定

现状：新建该模式任务保存开头策略，编译阶段重建来源连续映射。理由：不依赖模型记住硬约束。代价：合格来源和目标时长不足时必须拒绝；句中延长可能超过恰好40秒。

## ADR-004：本地任务状态与版本绑定

现状：SQLite事件、文件产物、输入指纹和运行时绑定协作恢复。理由：失败后能保留已完成工作且避免用不同工具继续旧任务。代价：升级和回退需要明确迁移，不能任意复用旧检查点。

## ADR-005：公开材料与商业核心分离

本次用户确认：公开文档、演示和安装入口，核心源码保留私有。公开仓库不包含模型、运行包、访问记录或私人素材；安装文件另经Release。代价：公众只能复核公开证据和文档，不能从该仓库独立复现私有Agent全部实现。
