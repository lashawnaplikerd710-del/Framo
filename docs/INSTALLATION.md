# 获取、安装与首次使用

## 当前下载入口

本仓库采用“文档公开、软件源码私有”的发布方式。进入当前GitHub仓库的 **Releases** 页面，选择具有明确版本、安装程序与SHA256校验文件的正式发行记录，再下载安装程序。不要把GitHub自动生成的Source code.zip当作软件安装包。

**此文档快照没有附带、重新生成或上传安装程序，也没有声明新的正式软件下载链接。** 如果Releases尚无安装程序，则该仓库当前只有文档可下载；维护者需完成软件发布检查后单独上传安装文件。正式发布的流程见[发布说明](RELEASING.md)。

已核实的现有安装程序为Framo-Setup-1.3.0.exe，大小1,591,784,802字节，SHA256为`95062db9c7d2859f0f8b337c773c3bb5acd196b7ef5abfb38f2d4b571bb5ca20`。本轮重新计算校验值一致；其已有验证范围见[安装版核验摘要](INSTALLER_VERIFICATION_1_3_0.md)。它尚未包含本机后来新增的批次不同开头逻辑，不能将文档中所有本机后续功能视为这个安装版已经具备。

## 系统准备

安装器目标为Windows 10 22H2／Windows 11，64位。选择空间充足且可写的目录，给模型、素材临时文件和成片预留空间。实际内存、磁盘和耗时取决于分辨率、时长及元素密度，目前没有跨硬件基准支持统一的最低性能承诺。

模型分析需要联网和有效访问码；本地渲染不等于整个流程全离线。是否需要网络代理取决于该设备实际能否访问网关，没有统一“必须VPN”的要求。先在设置中检测连接，不修改系统防护来绕过问题。

## 安装与使用

1. 从正式Release下载安装程序，核对SHA256与发行说明。
2. 安装到可写位置，通过桌面／开始菜单入口启动Framo。
3. 在设置中填写单独发放的工作台访问码，保存并检测网关。
4. 添加本地视频，选择剪辑模式、目标时长和成品数量；需要新配音时核对目标语言与音色。
5. 填写要求并创建任务，在任务页查看真实阶段进度。
6. 完成后软件内预览，打开成品目录检查实际MP4。需要处理时先查看中文原因，修正后再从检查点继续。

不要提交访问码到Issue。访问码期限、每日额度和累计次数由提供方管理，安装目录里的输入框不是授权管理入口。

## 文件位置

当前安装型代码将状态放在所选安装目录的 `UserData`，默认直接成品在 `UserData\Exports\Direct`，任务、临时文件和缓存也跟随安装位置。该规则要求安装分发具有对应安装配置标记。

开发者的旧便携运行目录有独立的历史状态路径，不能用开发者电脑路径推断别人安装后的路径。用户已更改成品目录时，以任务和设置中的实际位置为准。软件卸载流程保留UserData的设计不等于自动备份，重要素材与成片应自行保存。

## 验证范围

本轮只重新读取代码、采集界面并运行选定离线测试，没有在新电脑／虚拟机重装、升级或完成新的实付模型剪辑。安装兼容性以对应Release独立验证报告为准。
