# 路线图

以下是按当前证据提出的迭代顺序，不是已实现能力或确定交付日期。

| 优先级 | 事项 | 完成条件 |
|---|---|---|
| P0 | 修复类别开关误判KI-01 | 相同要求不再用字幕引用关闭音效／特效；增加针对性回归和实际成片轨道检查 |
| P0 | 统一发布快照KI-02 | 源码、运行模块、版本、安装输入对应；保留既有运行补充功能 |
| P1 | 完整创作要求验收 | 将技术合格、元素存在、语义符合和人工视听分层，不由完成状态代替 |
| P1 | 交付证据不可变归档 | 输出文件绑定任务／修订身份，定期核验历史路径与指纹，不能仅复用可变文件名 |
| P1 | 干净环境验证 | 独立用户或系统安装、路径、模型、音色、预览与完整任务通过并有报告 |
| P1 | 更清楚的自动修复与操作建议 | 真实缺资源、授权、格式、文案与执行问题分别展示；有界恢复和用量可见 |
| P2 | 长视频质量与性能基准 | 固定授权素材集、多分辨率、多硬件、多个模式；报告分布与失败样本 |
| P2 | 多样性与语义衔接评估 | 开头内容差异、后半段来源比例、语句接缝与重复分别衡量 |
| P2 | 素材与音色合规清单持续维护 | 来源、版本、署名和适用条款与实际分发对应 |

不将专业多轨编辑器、任意第三方效果完全复刻、全自动平台发布或无限修订写作当前承诺。
