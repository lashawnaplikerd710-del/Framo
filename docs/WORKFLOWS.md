# 产品工作流

## 日本区／美国区电商

导入素材 → 选择市场 → 核对目标语言与音色 → 输入真实商品要求 → 设置成品数 → 创建任务。模型结合可见证据规划镜头和本地化文案，当前默认策略可生成新口播与卖点字幕，并移除原声。用户明确要求和模式规则共同决定实际行为。

## 自定义剪辑

从空白要求开始，不强制广告结构。需要中文时明确写“中文／普通话口播、中文字幕”，并选择中文音色。只点选中文音色并不保证已切换任务的目标语言，目标语言和音色语言必须一致。

## 长视频

选择长视频后设置自动或目标时长，上限10分钟。按主题和章节组织信息；默认要求保留有价值的原声。新配音要明确指定并满足长度及声音资源条件；未指定目标时长时不强行撑满十分钟。

## 长视频（无口播）

这里的“无口播”是“不生成新的口播”，不是删除原素材声音。此模式保留原口播、原音乐和画面已有字幕，不生成新字幕、配音或BGM。

至少有一条素材的画面和原声达到40秒；成品目标至少40秒。程序连续保留该素材从零开始的前40秒，句中可延至完整语句结束。开头内部可加入装饰切点，但不能改变来源顺序、速度或连续性。后半段按完整语义交叉混剪，排除已使用的开头区间。

若批次需不同开头，在要求中明确写“本批七条的开头优先使用不同素材，七条之间不要重复，排除相同文件的重复副本”。需有足够不同内容来源；仅更换文件名不能算不同素材。

该批次多样性规则属于本机后续修改，现有1.3.0安装文件尚未包含；普通四十秒连续开头已在安装版中。使用前先核对对应发行记录。

## 批量与独立导出

成品数量为1至15，每条是独立子任务。常规队列默认一条执行，失败子任务保留错误，其他可继续排队。批次完成数要与实际独立MP4逐条对应。

直接成片任务完成时已经生成MP4，不应再次执行独立导出来证明完成。独立导出界面有其可用批次／草稿前提，不是所有直接成片任务的必经步骤。

## 要求优先与实际限制

关闭某类元素、指定某种效果或声明原声保留都应明确写出。已知的类别开关误判可能造成元素缺失，当前需要在成片和诊断报告中复核，见KI-01。任何动效密度都不能承诺平台去重通过。

复制即可使用的要求见[示例](../examples/BRIEFS.md)。
