# 数据与隐私说明

Framo采用本地优先处理，不应宣传为全离线产品。本页描述本轮读取实现的行为，不替代模型和网络平台各自的数据处理条款。

| 数据 | 处理位置与用途 |
|---|---|
| 原始视频 | 本机读取、探测、转写、抽帧和渲染；当前默认路径不把整段视频上传到网关 |
| 转写、要求和抽样画面 | 为模型理解／规划可能发送到网关和模型服务商 |
| 本机任务与成片 | SQLite、任务目录、缓存及用户选择的输出目录 |
| 模型API密钥 | 提供方或独立配置环境；不应随安装包或文档仓库发送 |
| 工作台访问码 | 用户本机凭据／调用；网关登记使用其哈希；凭证仍需按可泄露处理 |
| 网关请求状态 | 用户、请求编号、摘要、模型、状态、耗时等诊断信息 |
| 可恢复生成结果 | 受用户隔离和大小限制，当前策略短期保存24小时 |

网关没有主动保存完整提示词和素材图像的实现，不代表网络平台或模型服务商完全不处理这些数据；短期生成结果也可能包含用户内容，不能笼统说“服务端完全不保存内容”。

## 公开材料的排除范围

公开目录不包含真实访问码、授权登记、凭据文件、本机配置、用户素材、转写全文、任务数据库、缓存或私人输出视频。公开案例使用脱敏编号和技术计数，不附带源素材或人物画面。

本轮真实UI截图只覆盖空白创作页、类型列表和资源库，没有展示任务历史或设置凭据。它来自本机运行软件的空白创作会话，不是另一次干净系统安装验证。

## 留存与清理

本机文件由用户和软件路径管理；卸载保留UserData的设计可能保留任务和缓存，不应理解为自动清除全部内容。网关短期记录的过期删除依赖实际部署与平台任务执行，仍应在对应环境验证。

## 反馈问题

先按[反馈指南](../CONTRIBUTING.md)脱敏，隐藏访问码、个人路径、人物及私人素材信息。不要把完整工作目录或数据库放进公开Issue。
