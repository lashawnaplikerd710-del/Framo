# 故障排查

先记录模式、目标时长、成品数量、具体阶段与中文原因，再判断是否恢复。未读具体错误前不要连续点击重试。

| 现象 | 检查与操作 |
|---|---|
| 访问被拒绝／401 | 检查该码是否有效、停用或到期，联系提供方；不要把访问码发到Issue |
| 额度耗尽 | 区分每日加权单位和累计次数；一天50请求不是50成品 |
| 连接超时／响应结果不确定 | 确认该电脑网络与网关状态；可恢复请求先查已有结果，不盲目新建重复请求 |
| 文案过长／内容审核不通过 | 查看真实意见和完整旁白；检查目标时长与事实依据；自动修订仍失败时使用可用修复入口 |
| 渲染阶段很久 | 查看分段编号、已处理秒数、速度、最终编码或解码阶段；不只看最后一行时间 |
| 贴纸有、音效／特效没有 | 对照真实轨道与要求，当前可能命中KI-01；仅显示完成不能证明全部元素已加入 |
| 运行环境与保存任务不一致 | 不绕过绑定，交给维护者检查可否迁移；必要时新建任务 |
| 无法使用40秒开头 | 至少一份源视频画面和原声都达到40秒，目标总长不能短于40秒 |
| 后半段素材不足 | 不使用重复、变速或冻结来凑时长；补素材或调整目标 |
| 成品文件找不到 | 查看任务实际输出；安装型默认目录与开发者便携目录不同 |
| 预览无声音 | 检查成片是否有音轨、系统输出与软件播放状态；本轮未提供所有声卡的兼容承诺 |

提交问题时提供脱敏错误、阶段、模式、媒体时长／分辨率和复现步骤；不要提供访问码、API密钥、完整任务数据库或私人视频。如何反馈见[贡献说明](../CONTRIBUTING.md)。
