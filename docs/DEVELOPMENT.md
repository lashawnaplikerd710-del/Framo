# 私有开发与公开协作边界

本仓库公开产品和技术资料，核心应用、工作台实现、网关管理实现及私有运行配置不在此仓库发布。文档可在本地校验；对产品实现的修改在私有代码目录执行并独立评审。

## 已核实的开发栈

- Python 3.12与Tkinter/ttk：桌面界面、任务编排、数据库及进程管理。
- FFmpeg／FFprobe：本地探测、渲染、合成和解码检查。
- SenseVoice：本地转写；时间为识别产生的近似语义时间，不是强制对齐保证。
- Kokoro／Sherpa-ONNX／VOICEVOX等本地音色链路：按具体包和音色条款使用。
- Node.js、Cloudflare Workers和Durable Objects：网关执行与额度／恢复状态。
- Pillow、NumPy等媒体处理依赖：按锁定运行包和相应许可提供。

基础requirements文件不足以代表完整语音、模型和多媒体运行包。公开文档不提供一条未经验证的pip命令来声称可以从空环境恢复完整应用。

## 私有研发检查

1. 在源码目录运行受影响模块的unittest；不要把Mock提供方测试写成真实模型调用。
2. 对实际运行模块重复关键测试，比较文件指纹；不能整目录覆盖运行时的独立功能。
3. 用固定输入验证真实输出，分别记录技术结果、语义符合性和人工视听结论。
4. 生成干净安装包并在独立用户／系统环境验证，保留真实报告。
5. 将可以公开的脱敏结论同步到本仓库，私人日志和素材保持私有。

本轮执行的测试模块与结果见[评估报告](EVALUATION.md)。源码与运行目录不一致的现状见[版本](VERSIONING.md)，需要在下一次正式软件发行前处理。
