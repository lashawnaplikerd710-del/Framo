# 交互与视觉规范

本轮文档整理沿用现有UI，没有重新设计或修改业务界面。截图是2026-10-20打开当前本机软件采集的真实像素，不是概念稿。

## 界面分区

左侧为新建剪辑、模板库、任务与草稿、独立导出、设置；主区域承载素材／预览／任务表；右侧承载创作设置或任务详情。主操作置于当前流程可见位置，创建、继续和导出均应反映实际可用状态。

## 关键状态

- 无素材：主预览显示添加入口，素材数为0，不出现虚假的成品预览。
- 已导入：可选择、预览、移除素材；输入技术限制由后端复核。
- 排队／执行：显示阶段和实际进度；日志应跟随最新事件，允许用户查看历史。
- 失败／需要处理：原因使用中文说明，提供处理建议和可用恢复入口。
- 完成：实际MP4与报告存在后提供预览与目录入口，不用状态文字代替产物检查。

## 资源选择

音色单击选择并试听，以右侧勾选表示当前选中，按中文／日语／英语分别记忆选择。长视频无口播模式禁用新音色和字体入口，避免把“不生成新配音”理解成“没有原声”。

贴纸库展示真实资源及来源信息；高级立体分类当前显示15款，全部目录条目数另行统计。界面预览资源不表示已加入当前任务，自动编排发生在任务执行阶段。

任务列表按新任务优先展示；成品生成目录与独立导出目录需明确区分。错误原因和进度的实际完善程度仍受[已知问题](LIMITATIONS.md)约束。
