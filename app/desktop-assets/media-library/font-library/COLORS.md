# 字幕颜色怎么指定

字体决定字形；字幕字色、描边色和底板色单独指定。当前 Framo 直接渲染原先固定白字，本次修复已把这些属性从剪辑要求传到时间轴、字幕 PNG 和 FFmpeg 成片。

可以直接复制到软件剪辑要求：

```text
添加字幕，字幕用黄色，黑色描边，不要底板。
```

```text
添加字幕，字幕颜色 #FF69B4，描边色 #163B70，底板色 #00000080。
```

```text
添加字幕，白色字幕，黑色描边，底板为深蓝色。
```

支持纯色文字、描边、底板、去掉底板及去掉描边。渐变、关键词逐词不同颜色、图案装饰和动画需要后续样式模板实现。已烧录在素材画面里的旧字幕无法通过新字幕颜色设置直接改色。

## 可用色值示例

| 用途 | 颜色 | 精确色值 |
| --- | --- | --- |
| 通用字色 | 白色 | #FFFFFF |
| 强调字色 | 黄色 | #FFFF00 |
| 柔和字色 | 奶油黄 | #FFEBAE |
| 活泼字色 | 粉色 | #FF69B4 |
| 柔和粉色 | 浅粉色 | #F9A8D4 |
| 清爽字色 | 薄荷绿 | #A3FFD9 |
| 科技字色 | 浅蓝色 | #93C5FD |
| 展示字色 | 紫色 | #A855F7 |
| 促销字色 | 红色 | #FF0000 |
| 展示字色 | 金色 | #FFD700 |
| 深色描边 | 黑色 | #000000 |
| 深色描边/底板 | 深蓝色 | #163B70 |
| 半透明底板 | 黑色、约 50% 不透明度 | #00000080 |
| 去掉底板 | 透明 | #00000000 |

常用中文颜色名称会映射成固定色值；对颜色有准确要求时使用十六进制色值。六位表示 RGB，八位最后两位表示不透明度（00 全透明、FF 不透明）。

用户明确指定的颜色覆盖软件默认颜色和每条字幕已规划的配色。未指定时沿用已有字幕计划配色，普通字幕默认白字黑边、半透明黑底板；当前尚未实现按背景逐镜头自动计算最佳配色。

## 验证

回归测试检查了文字、描边和底板独立改色，去掉底板、纯色十六进制、否定要求以及商品颜色不会被当成字幕颜色。真实 FFmpeg 输出另外验证了黄色、粉色、薄荷绿字幕的编码后像素。颜色修复的代码快照见 runtime-color-patch。
