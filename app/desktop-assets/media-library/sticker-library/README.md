# Framo 立体贴纸库 v5

共 100 款 Microsoft Fluent 立体贴纸：保留原 47 款，新增 53 款；玻璃贴纸已从使用库和本交付包移除。

全部从微软官方 GitHub 仓库的固定提交下载，保留原始 256×256 透明 PNG，没有使用 AI 生成或通过放大冒充更高精度。用于目前约 72～180 像素的成片角落贴纸布局。

来源：https://github.com/microsoft/fluentui-emoji 。随软件分发保留 LICENSE-microsoft.txt。manifest.json 逐项记录原始 URL、提交版本、SHA-256、主题和关键词。

新增素材涵盖服饰、美妆、电子产品、食品、运动、自然、宠物、庆祝和教育。根据选中镜头的画面识别结果匹配具体物品和主题；主题不明确时只用中性装饰。输入“不要贴纸”可关闭。字体库不受本次更新影响。

关闭并重新打开 Framo 后，新建任务使用；原任务缓存不重写。当前没有主体自动避让、位置跟踪或贴纸动画。发布安装包未重新构建。
